# Web Fundamentals

HTML, CSS, and JavaScript assignments from the Skillspire Full Stack Web Development Immersive (weeks 1-4, October 2026).

These are course assignments, kept as a record of what I covered while learning the fundamentals of how the web works. My main focus going forward is Python and backend development.

## HTML

| Folder                        | What it shows                                     |
| ----------------------------- | ------------------------------------------------- |
| `HTML/my-favorite-food`       | Basic page structure, headings, lists, and images |
| `HTML/tables-and-rows`        | Building tables with rows and cells               |
| `HTML/user-registration-form` | Form inputs, labels, and dropdowns                |

| Folder                   | What it shows                                                                                      |
